# Update 2026-08-12 – Compose/Health/CI

Dieses Paket enthält nur die Dateien, die gegenüber dem aktuellen Repository ersetzt oder neu hinzugefügt werden müssen.

## Enthaltene Änderungen

- `compose.yaml`
  - explizite Healthchecks für Unbound und Pi-hole
  - Unbound-Healthcheck ohne Abhängigkeit von einer externen Testdomain
  - Pi-hole wartet auf healthy Unbound
  - Environment-Werte für boolesche Pi-hole-Optionen explizit als Strings
- `unbound/Dockerfile`
  - lokaler, deterministischer Healthcheck gegen `localhost`
- `scripts/preflight.sh` **neu**
  - Docker/Compose/Secret/Compose-Konfiguration prüfen
  - DNS-Portkonflikte vor dem Start erkennen
- `scripts/start.sh`
  - Preflight automatisch ausführen
  - verständliche Fehlerdiagnose + Logs
  - auf healthy Container warten
- `scripts/status.sh`
  - Status, Health und Restart-Zähler sauber anzeigen
- `scripts/test-dns.sh`
  - echte End-to-End-Tests für Rekursion, DNSSEC und Pi-hole → Unbound
  - keine festen temporären Dateinamen mehr
- `.github/workflows/validate.yml`
  - `actions/checkout@v7`
  - Images bauen
  - Container tatsächlich starten
  - Healthchecks abwarten
  - DNS/DNSSEC-Integrationstest ausführen
  - Logs bei Fehlern ausgeben
- `README.md`, `docs/TROUBLESHOOTING.md`, `Makefile`
  - neue Prüfungen dokumentiert/eingebunden

## Einspielen

Die Dateien dieses Update-Pakets in das Root-Verzeichnis deines geklonten Repositories kopieren und vorhandene Dateien ersetzen.

Danach:

```bash
chmod +x scripts/*.sh unbound/entrypoint.sh
./scripts/preflight.sh
./scripts/build.sh --pull
./scripts/start.sh
./scripts/test-dns.sh
```

Vor einem Update einer produktiven Installation empfiehlt sich wie bisher ein Backup:

```bash
./scripts/backup.sh
```
