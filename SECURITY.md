# Sicherheitsrichtlinie

Bitte melde Sicherheitsprobleme **nicht öffentlich als GitHub Issue**, wenn dadurch ein ausnutzbarer Fehler oder ein Secret offengelegt würde.

Nutze für das Originalprojekt bevorzugt GitHub **Private Vulnerability Reporting / Security Advisories** unter:

https://github.com/BlackRabbitZ/PiHole-Unbound-Docker/security

## Scope

Im Scope sind Sicherheitsprobleme in den von BlackRabbitZ erstellten Compose-, Docker-, Shell- und Konfigurationsdateien dieses Repositories.

Probleme in Pi-hole, Unbound, Alpine Linux oder Docker selbst gehören in die jeweiligen Upstream-Projekte.

Bitte keine echten Zugangsdaten, privaten DNS-Logs oder internen Netzwerkdaten mitsenden.
