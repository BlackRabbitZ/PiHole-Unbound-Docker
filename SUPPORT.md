# Support

## Reihenfolge bei Problemen

1. [`README.md`](README.md) prüfen.
2. [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md) durcharbeiten.
3. `./scripts/status.sh` ausführen.
4. Bereinigte Logs mit `./scripts/logs.sh` prüfen.
5. Falls es ein Fehler in diesem Repository ist, ein GitHub Issue erstellen.

Bitte niemals Webpasswörter, Secrets, private DNS-Logs oder unnötig genaue interne Netzwerkdaten veröffentlichen.

Sicherheitslücken bitte gemäß [`SECURITY.md`](SECURITY.md) privat melden.
